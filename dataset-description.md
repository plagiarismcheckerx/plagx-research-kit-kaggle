*A free academic writing utility by Plagiarism Checker X.*

Ready-to-use academic research templates from the **Plagx Research Kit** notebook, which shows how to keep a source log and turn it into APA 7 or MLA 9 citations.

## Files

| File | What it is |
|---|---|
| `source_log_template.csv` | Blank source log: one row per source, with quotes and page numbers |
| `source_log_example.csv` | The same log filled in with fictional example sources |
| `literature_matrix.csv` | Compare sources by method, findings, limitations and themes |
| `annotated_bibliography.md` | Example annotated bibliography built from the log |
| `research_plan.md` | Research question, scope, search strategy and timeline |
| `references.json`, `references.bib` | The example references as CSL-JSON and BibTeX (for Zotero, Mendeley or LaTeX) |
| `plagx_cite-*.whl` | The open-source [plagx-cite](https://pypi.org/project/plagx-cite/) package (MIT), so the notebook runs without internet |

All example sources are made up.

## What this does not do

These templates do not check for plagiarism or detect AI-generated text. To check complete documents, use [Plagiarism Checker X](https://plagiarismcheckerx.com/?utm_source=kaggle&utm_medium=dataset&utm_campaign=plagx-research-kit).
